# Авантюра — мобильный интерфейс

Верстка экранов по [макету Figma](https://www.figma.com/design/bKFrm0tCaoFhiN6yWeIweu/Untitled?node-id=0-1). Приложение собрано на Expo, React Native, TypeScript и NativeWind v4.

## Запуск

```bash
npm install
npm start
```

В терминале Expo нажмите `a` для Android, `i` для iOS или `w` для браузера. Для отдельного запуска веб версии: `npm run web`.

## Что реализовано

- Регистрация, вход и три шага настройки профиля.
- Главный экран с картой, фильтрами и встречами; чаты, уведомления и профиль.
- Карточка встречи, подтверждение и защита участия, чат встречи.
- Создание и отправка пинга.
- Состояния загрузки, ошибки с повтором и пустого списка для данных из API.

Данные экранов предоставляет типизированный мок в `src/api/mocks/`. Компоненты используют интерфейс `AdventureApi` через `src/api/index.ts`; при подключении сервера можно заменить реализацию этого интерфейса. Карта пока служит визуальной частью макета, без геопозиции и живых маркеров.

Плашка времени и Wi‑Fi из макета не входит в верстку: в мобильной сборке используется системная строка состояния.
